# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be respectful, assume good faith, critique code not
people, and keep discussions on the work. Harassment, personal attacks,
and sustained disruption are not tolerated.

Reports: use GitHub's report feature on the relevant content, or contact
the maintainer privately via the email on their GitHub profile. Reports
are handled confidentially.
