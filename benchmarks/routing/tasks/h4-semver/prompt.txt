Create a new Go package at internal/semver/semver.go (package semver) with `func Compare(a, b string) int` implementing Semantic Versioning 2.0.0 precedence. Return a negative number if a < b, zero if equal, positive if a > b. Rules: compare major, then minor, then patch numerically. A version WITH a pre-release has LOWER precedence than the same version without one. Pre-release is dot-separated identifiers compared left to right: identifiers made of only digits compare numerically; others compare lexically in ASCII order; a numeric identifier always has lower precedence than a non-numeric one; if all shared identifiers are equal, the version with MORE identifiers has higher precedence. Build metadata (a "+" suffix) is ignored entirely. Leading "v" may be present or absent. Add a one-line package doc comment.
