How it decides

Signals → grid search → decision → log

Four built-in providers assess a task — prompt shape, file scope, recent git churn, adjacent test coverage — each contributing a complexity estimate and a confidence in that estimate. The kernel picks the cheapest (model, effort) cell that clears the evidence-backed floor. Missing or unreliable evidence never buys a cheaper answer: it defaults to the ceiling.

The five axes

Every axis has a mode: off, advise, or enforce

on / off

Preprocessing

Rewrites verbose Bash commands (test/build/lint runs, large log tails) before they execute, so the output never lands. Exit-code-safe, never guesses at semantics.

advise

Effort

Injected guidance on when to ask for lower effort on mechanical steps. Inert if CLAUDE_EFFORT pins the session — /deadeye-status says so plainly.

advise / enforce

Model routing

Recommends or rewrites the model on Agent-tool delegations, using the same kernel decision /deadeye-route shows you. Never overrides an explicit model request.

soft / hard

Plan gate

Suggests a plan-first approach on vague or multi-file prompts. The hard layer (off by default) asks for permission before an ungated Edit/Write.

recommend-only

Workflow advisor

Flags genuinely fan-out tasks ("audit every file across the codebase") with a one-line suggestion. Never triggers a workflow itself — only ever a suggestion.

FAQ

Does it phone home?

No telemetry, no network calls at runtime. One JSONL file, local, at ~/.deadeye/.

How do I turn it off?

DEADEYE=off disables everything. DEADEYE_PREPROCESS=off and DEADEYE_GATE=off disable just those axes.

How do I uninstall?

deadeye uninstall --purge removes the binary, the daemon socket, and ~/.deadeye entirely.

What if a hook errors?

Every hook fails open: an error or panic anywhere always yields a no-op response. A broken policy layer should never block real work.
