claude code mod · themes

Sixteen looks. Pick one you can see first.

Each card is the same moment of a session — a tool row, a block, the finish line, the HUD band and the prompt — drawn in that theme. The spinner verbs, finish word and block tag belong to the theme too; the numbers are examples.

Turn the mod on once: deadeye config set mode.mod on. Then pick from inside Claude Code with /deadeye theme (a list; enter keeps), set one by name with /deadeye theme nord, or from a shell with deadeye config set mod.theme nord. The same key either way; it applies on the next turn.

With mod.repaint on (the default) the theme also recolours Claude Code's own accent, prompt border and diffs. Your terminal's background and font stay yours — the card backgrounds show each palette's intended terminal colours.
